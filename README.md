#Weather App Project
##Intro
I am a second year student at NSCC for IT Programming and this app is a project for my Mobile Development Class. This project was broken down into Sprints throughout my third semester. 

##Features
- Current Weather Screen
- Forecast Screen
- Navigation
- Custom launcher icon
- Custom user interface
- Responsive Jetpack Compose Layout

##Technologies
- Kotlin
- Jetpack Compose
- Android Studio
- Aseprite
- Google Fonts

  ##Design
  The icons were created by me using Aseprite and the fonts are from GoogleFonts. The design was inspired by
  - Vintage IBM computers
  - Vintage CRT monitors
  - Green phosphor terminal display
  - Retro computer interfaces
  - Pixel-art
